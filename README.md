## 📌 アプリの概要

**mk-stinger** は、OBS Studio などの配信ソフトで使用できる **スティンガートランジション動画（トラックマット WebM）** を、インストール不要・ブラウザ完結でリアルタイムに作成・出力できるジェネレーターです。

従来の動画編集ソフトを使わずとも、幾何学アニメーションやサイバー調のスティンガーをパラメータ調整しながら作成でき、OBS のトラックマット（横並び）形式としてそのまま書き出せます。

### ✨ 主な特徴

- ⚡ **インストール不要＆ブラウザ完結**: 動画のアップロードや外部サーバー処理は一切不要。PCのブラウザ（WebCodecs API）で高速にエンコードして直接ダウンロードできます。
- 📐 **OBSトラックマット完全準拠 (Side-by-Side)**:
  - 3840×1080 (1080p) / 2560×720 (720p) の横並びトラックマット動画を出力。
  - 左半分にアルファ透過アニメーション映像、右半分にシーン切替マスク（黒: Scene A → 白: Scene B）を合成。
  - マスクでシーン切り替えが完結するため、OBS 側での移行ポイント（フレーム数 / ミリ秒）入力は不要です。
- 🎨 **豊富な組み込みプリセット & カラーカスタマイズ**:
  - **HEX**: 画面左から六角形が充填され、収縮消滅するハニカムトランジション
  - **Line Wipe**: 斜めラインが重なり合いながら画面を横断するワイプトランジション
  - **Decorated Line**: 星やハート、任意のカスタム画像（PNG/SVG・ドラッグ＆ドロップ対応）がラインに沿って舞うデコレーションワイプ
  - **Hyper Jump**: 画面外側から中心へ光のリングが収縮し、フラッシュと同時に次シーンが中心から広がるワープトランジション
  - **Slash**: スピード感ある複数の鋭角スライスブレード
  - **Cyber Grid (Glitch)**: GitHubの草カラーを基調としたデジタルブロック・グリッドトランジション
  - 8種のカラーテーマプリセット（Tokyo Night / Dracula / Catppuccin 等）、HSL色彩理論に基づくランダム配色、ボーダー色と独立したグロー色の設定に対応。プリセット切替時も調整中のカラーや各プリセットの設定ドラフトを保持します。
- 🎮 **配信切替シミュレーター & プレビュー機能**:
  - プレビュー上で「Scene A → Scene B」の実際の切り替え動作をリアルタイムに確認可能。
  - 任意の配信画面スクリーンショット等を Scene A / Scene B に読み込み可能（ファイル選択・ドラッグ＆ドロップ対応）。
  - **1回切替テスト**（Scene A から 1 回再生して Scene B で停止）、**ループ再生 ON/OFF**、**白黒マスク単体表示**、**全体 32:9（Side-by-Side）表示**、コマ送り・シークバー・キーボードショートカットに対応。
- 🔗 **設定の URL 共有**:
  - 現在のプリセット・カラー・各種パラメータ・出力設定を URL クエリとしてワンクリックでコピー・共有し、URL を開くだけで設定を復元できます（カスタム画像は対象外）。

## 🚀 起動方法

### 前提要件
- **Node.js**: v18.0.0 以上
- **ブラウザ**: WebCodecs API に対応したモダンブラウザ（Google Chrome, Microsoft Edge など Chromium 系を推奨）

### 手順

1. **リポジトリのクローン**
   ```bash
   git clone https://github.com/d11j/mk-stinger.git
   cd mk-stinger
   ```

2. **依存パッケージのインストール**
   ```bash
   npm install
   ```

3. **開発サーバーの起動**
   ```bash
   npm run dev
   ```
   起動後、ターミナルに表示されるローカルURL（通常は `http://localhost:5173`）をブラウザで開きます。

### その他のコマンド

- **プロダクションビルド**:
  ```bash
  npm run build
  ```
- **ビルド成果物のローカルプレビュー**:
  ```bash
  npm run preview
  ```
- **ユニットテスト実行 (Vitest)**:
  ```bash
  npm test
  npm run test:watch
  ```
- **静的解析 / フォーマット (ESLint / Prettier)**:
  ```bash
  npm run lint
  npm run lint:fix
  npm run format
  npm run format:check
  ```

## 🎥 OBS Studio での設定手順

mk-stinger でエクスポートした動画は、以下の手順で OBS Studio に登録できます。

1. OBS Studio の「**シーントランジション**」ドックを開き、追加（`+`）から「**スティンガー**」を選択。
2. 「**動画ファイル**」で出力したファイル（`.webm`）を選択。
3. 「**トラックマットを使用する**」にチェックを入れる。
4. 「**トラックマットのレイアウト**」を **同じファイル、並べて表示（横並び）** に設定。
5. 「**プレビュー**」で切り替わりを確認し、「**OK**」を押して設定完了です（トラックマット有効時は移行ポイントの入力は不要です）。
